{% comment %} Justified gallery of everything in /images/gallery/ (newest name first). Usage: include gallery.html — or pass limit=3 to show only the first few. How it works (flexbox + one CSS variable per photo): - --r is the photo's aspect ratio (width / height). Jekyll can't read image sizes on GitHub Pages, so the script at the bottom sets it once each photo loads (1.5 until then). - each box starts at the width it would have at the target row height: flex-basis = --r * --row-h (--row-h is set on .gallery, bigger on wider screens) - flex-wrap fills a row until the next photo won't fit, then wraps - flex-grow = --r, so wide photos grow more than tall ones in exactly the same proportion: every photo in a row ends up the same height, and aspect-ratio = --r means NOTHING is cropped (rows can be a little taller or shorter than --row-h — that's the trade-off) - the invisible ::after spacer (grow 10) soaks up space in the LAST row, so a lone photo there doesn't get blown up to full width {% endcomment %} {% assign exts = ".jpg,.jpeg,.png,.webp,.gif" | split: "," %} {% assign photos = site.static_files | where_exp: "f", "f.path contains '/images/gallery/'" | sort: "name" | reverse %} {% assign limit = include.limit | default: photos.size %} {% if photos.size == 0 %}
