# Title card images

One background image per page, shown behind the big heading at the top.

- These `.svg` files are **placeholders** — swap them for real photos.
- Best format: landscape JPG, about **2400 × 1200 px**, under ~500 KB.
- To use a new image, drop it in this folder and change `hero_image:`
  in the front matter at the top of that page's `index.html`.
- If the subject gets cropped badly, set `hero_position:` (e.g. `top`, `30% 60%`).
